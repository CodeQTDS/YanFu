# Configuration guide · v1.0

Start with `npm run setup`. It copies safe templates into ignored local files without overwriting an existing file. Backend configuration is loaded from the project's `config/` directory; `.env` is loaded at backend startup. Restart the backend after edits and refresh the browser.

## Environment variables

Keep credentials only in the ignored `.env` or your shell. Never put them in the frontend or tracked JSON files.

| Variable | Default/template | Meaning |
|---|---|---|
| `PORT` | `3000` | Backend port; browser API_BASE and app frontend metadata must also match if changed |
| `YANFU_BIND_HOST` | `127.0.0.1` | Local-only listener; external binding is rejected |
| `AI_DEFAULT_MODEL` | `modelscope:qwen3.5-27b` | Catalog `id` used when a request does not select a model |
| `AI_REQUEST_TIMEOUT_MS` | `1200000` | Provider timeout in milliseconds |
| `AI_MAX_OUTPUT_TOKENS` | `4096` | Requested model output limit; provider behavior varies |
| `YANFU_LOG_LEVEL` | Unset; app config uses `verbose` | `off`, `error`, `info`, `verbose`, or `debug` |
| `YANFU_ALLOWED_ORIGINS` | localhost and 127.0.0.1 on 5500/5501 | Exact comma-separated frontend origins, no path and no wildcard |
| `YANFU_API_MAX_REQUESTS_PER_MINUTE` | `240` | Per-IP non-GET API request limit |
| `YANFU_API_MAX_ACTIVE_AI_REQUESTS` | `3` | Concurrent expensive API request limit |
| `YANFU_REVIEW_ATTESTATION_SECRET` | Unset | Optional private secret, at least 32 bytes; stable across restarts if supplied |
| `MODELSCOPE_API_KEY` / `MODELSCOPE_BASE_URL` | Blank key / bundled URL | ModelScope credentials and endpoint |
| `OPENAI_API_KEY` / `OPENAI_BASE_URL` | Blank key / bundled URL | OpenAI credentials and endpoint |
| `GEMINI_API_KEY` / `GEMINI_BASE_URL` | Blank key / bundled URL | Gemini credentials and endpoint |
| `ANTHROPIC_API_KEY` / `ANTHROPIC_BASE_URL` | Blank key / bundled URL | Anthropic credentials and endpoint |
| `OLLAMA_URL` | `http://127.0.0.1:11434/api/generate` | Local generation endpoint |
| `OLLAMA_TAGS_URL` | `http://127.0.0.1:11434/api/tags` | Local model discovery endpoint |

If receipts use the process-generated ephemeral secret, a backend restart invalidates them. A supplied stable secret does not bypass the 24-hour receipt expiry. Do not place wallet keys or recovery phrases in `.env`; browser signing is performed by MetaMask.

PowerShell sets environment variables with `$env:NAME='value'`; remove a temporary override with `Remove-Item Env:NAME`. A `.env` file uses `NAME=value` without `$env:`. Existing process environment values take precedence over `.env` values.

## Chain configuration

`config/chain.config.json` is ignored and normally generated by `npm run deploy`. `config/chain.config.example.json` is a complete safe shape with public disposable-chain example addresses. Treat those addresses as examples until your own deployment writes actual values.

Required keys:

| Key | Value type |
|---|---|
| `rpcUrl` | HTTP local RPC URL |
| `chainId` | Numeric ID of that exact chain |
| `token`, `governor`, `timelock`, `treasury`, `contractFactory`, `daoSettings` | Deployed 20-byte Ethereum address strings |

For a custom local chain, update `hardhat.config.js` as needed before starting it, deploy to that chain, then match MetaMask to the resulting config. Changing only the JSON chain ID does not change the actual chain. Do not copy live-network credentials into RPC URLs in tracked examples.

## Deployment configuration

The shipped file is:

```json
{
  "timelockMinDelaySeconds": 120,
  "treasuryTokenAllocation": "900000",
  "openExecutor": true,
  "grantGovernorAsSoleProposer": true
}
```

- Delay is in seconds; allocation is a human MTK decimal string.
- Open execution authorizes the zero-address role. With `openExecutor=false`, Governor receives executor permission.
- The current deployment script grants Governor the proposer role. `grantGovernorAsSoleProposer` is a retained descriptive configuration field; it is not a general role-revocation switch, and the script does not implement alternative behavior when it is changed.
- Deployer retains admin permission for local recovery. This is not a production role-handoff plan.
- Changes affect future deployments, not existing contracts.

## Model catalog

Provider configuration names environment variables rather than storing credentials. A model entry distinguishes:

```json
{
  "id": "modelscope:qwen3.5-27b",
  "provider": "modelscope",
  "model": "Qwen/Qwen3.5-27B",
  "label": "Qwen 3.5 27B",
  "tier": "ONLINE",
  "supportsJson": true,
  "supportsTemperature": true
}
```

`id` is YanFu's stable lookup key; `model` is sent to the provider. Use the provider's exact accessible model name. Flags and `apiStyle` must match the existing adapter's capabilities. Do not assume every model supports the same transport or sampling options. `CONFIGURED` means the key exists locally, not that a live provider call succeeded.

## Reviewer and workflow policy

`reviewers.config.json` defines 1–5 slots, profile IDs, prompts and default assignments. Same-model/different-role is allowed; identical model+role pairs are rejected. Aggregate approval is unanimous and a rejection dominates. Changing these settings changes functionality and is outside the version-label adjustment.

`app.config.json` keeps sequential navigation, analysis-before-review, review-before-submit and post-edit validation enabled. It also defines human edit and review-result overrides. Overrides require explicit acknowledgment; they do not turn stale advice into fresh approval.

Numeric `version` fields in capabilities/policy/config files are schema revisions. `apiVersion`, review hash namespaces, model versions and the browser storage key are internal compatibility data. They are not YanFu release labels and must not be mass-replaced.

## Registered contracts and other optional configuration

`registered-contracts.example.json` is empty by default. `registered-contracts.catalog.example.json` shows disabled ownership/pause/upgrade and DEX entries. Copy only a verified entry into your ignored `registered-contracts.json`, replace the address and ABI, and deliberately enable it. The full guide is [CAPABILITIES.md](CAPABILITIES.md).

`ui.config.json` contains navigation metadata. `prompt-templates.json`, `review-policy.json` and `input-validation.json` affect interpretation and safety behavior; edit only with relevant regression tests. None should contain secrets: public configuration routes expose selected contents to the browser.
